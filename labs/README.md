# Hands-on Labs

48 guided practical labs, one per session: `week-XX/LAB-WXXDYY/README.md`. Use `starter/` for only intentionally provided scaffolding, `submission/` for learner work, and `tests/` for learner-created checks. Never publish hidden solutions in this repository.

Every lab has: required objectives, task, deliverables, acceptance criteria, optional challenge, and self-review questions. Code is written by learner, Agent offers progressive hints.
