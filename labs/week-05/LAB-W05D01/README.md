# LAB-W05D01: Effects and external systems

**Buổi:** W05D01 · **Dự kiến:** 50 phút Independent Lab, ngoài 16 phút guided coding và 10 phút debugging.

## Pre-lab reading (24 phút theory)
https://react.dev/reference/react/useEffect

## Recall (10 phút)
Ôn nhanh kiến thức từ bài trước bằng một nhiệm vụ code nhỏ do Agent đặt. Buổi đầu sử dụng bài chẩn đoán kiến thức nền.

## Guided coding (16 phút)
Agent minh họa một tình huống gần với bài Lab, không cung cấp lời giải của yêu cầu chính. Học viên tự chạy code và giải thích kết quả.

## Required task (50 phút)
**Synchronize a timer and document title**

Concepts: useEffect, cleanup, dependencies.

### Acceptance criteria
- Bài chạy được và có thể demo hành vi chính, không chỉ đưa screenshot.
- Giải thích được ý nghĩa của useEffect, cleanup, dependencies khi áp dụng trong bài.
- Xử lý đầu vào hoặc trạng thái bất thường tương ứng với nội dung buổi học.
- Mã nguồn có cấu trúc rõ ràng, type hợp lý (nếu đã học TypeScript), không chứa credentials.

## Submission
Lưu source code dưới `submission/` hoặc dự án đang học và trỏ đường dẫn cụ thể trong event nộp bài. Ghi cách chạy, test và điều đã tự làm. Không có đáp án mẫu trong repo.

## Debug and tests (10 phút)
Chạy code và thử ít nhất 1 edge case; ghi lại lỗi đã sửa. Agent hướng dẫn gợi ý theo cấp độ, không làm hộ.

## Assessment (10 phút)
Agent xem code và bằng chứng, yêu cầu học viên giải thích, chấm theo `assessments/rubrics/default.md`. >=75/100 và đạt tất cả chức năng bắt buộc thì pass; nếu không thì `needs_revision` và học tiếp phiên sau.

## Optional challenge
Tự bổ sung một tính năng hoặc edge case có liên quan, ghi rõ phần tự làm và phần nhận hỗ trợ AI. Bonus không thay thế Required.
