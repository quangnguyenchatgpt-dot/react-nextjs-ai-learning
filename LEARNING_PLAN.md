# Learning Plan — 16 weeks / 48 sessions

**20% theory / 80% practice**, 3 days each week, 2 hours each day. Review 10m (active recall / mini coding), theory 24m, guided coding 16m, independent lab 50m, debug/testing 10m, assessment 10m.

Each session maps to `curriculum/weeks/week-XX/day-YY.md` and `labs/week-XX/LAB-WXXDYY/README.md`. Advance only after a reviewed submission passes >=75 and mandatory functionality. A lab may take multiple calendar days. `progress/daily/` contains durable session records.
