# Lộ trình 16 tuần (96 giờ)

- Tuần 01–02: HTML, CSS, JavaScript, TypeScript, React JSX.
- Tuần 03–04: Props, events, state, forms, lists, effects, API, custom hooks, checkpoint.
- Tuần 05–06: useRef, useReducer, memoization, Context, Zustand, Redux.
- Tuần 07–10: TanStack Query, mutation, React Hook Form, Zod, advanced forms, checkpoint; Next.js foundations.
- Tuần 11–12: Next.js rendering, data fetching, route handlers, MUI components, layouts.
- Tuần 13–14: MUI, design systems, responsive/accessibility, Refine.
- Tuần 15–16: Auth, testing, integration, final defense.

**Mỗi buổi 120 phút:** 15' review, 25' explanation, 60' coding, 20' assessment. Chi tiết và nguồn tài liệu nằm trong 48 lesson files. Đây là ước lượng; có thể học lại trước khi đạt threshold.

**Dự án xuyên suốt:** Automation Management Dashboard giả lập (không dùng dữ liệu thực), gồm Robots, Jobs, Runs, form validation, pagination, error states, authentication demo, tests.

**Cách dùng:** "Agent, đọc progress, bắt đầu bài tiếp theo và không làm hộ bài tập."
