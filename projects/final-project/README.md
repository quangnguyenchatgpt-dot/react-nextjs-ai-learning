# Capstone: Automation Management Dashboard

Build a **mock-data** admin console for a fictional automation platform. No real credentials or patient information.

## Scope
- Robots index, robot details and status
- Jobs list, create, edit, delete with Zod + React Hook Form
- Job runs and status, filters and pagination
- Next.js App Router and MUI responsive layout
- Refine resources/data provider integration
- Auth demo with public/protected pages (not production auth)
- Loading, empty, error and accessibility states
- Component/integration tests; README explaining design

## Acceptance criteria
Successful build and tests, usable CRUD flows, meaningful validation, documented limitations and independent architecture presentation. Check assessment rubric.
